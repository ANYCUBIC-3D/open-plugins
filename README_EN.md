# OpenPlugins

OpenPlugins is an open-source library that provides plugin infrastructure for AnycubicSlicerNext. The project simplifies the plugin development process by providing essential functional modules needed for plugin development, enabling developers to build and integrate plugins more conveniently.

## Features

* **Modular Plugin Architecture**: Provides clear plugin interface definitions supporting independent development, deployment, and management of plugins
* **Unified Communication Protocol**: Implements reliable communication between plugins through memory stream-based data transmission
* **Event-Driven Model**: Supports event listening and response, facilitating interaction between plugins
* **WebView Integration**: Built-in wxWebView support
* **Plugin Package Management**: Supports plugin packaging, signature verification, and version management
* **Internationalization Support**: Built-in multi-language support
* **XRC Support**: Supports using XRC files to define plugin interfaces
